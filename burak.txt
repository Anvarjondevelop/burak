HTTP so‘rovlarni qabul qilish, routing va response qaytarishni osonlashtiradi.
---------------------------------------------------------------------------------------------------------
app.use(express.static(path.join(__dirname, "public")));
1/ app.use(...) — middleware ulash => “Har kelayotgan request oldin shu funksiyadan o‘tsin”

2 /express.static(...) — static fayllar uchun middleware
express.static(...)
 Bu tayyor middleware bo‘lib:
HTML,CSS,JS,IMG,FONT kabi o‘zgarmaydigan (static) fayllarni to‘g‘ridan-to‘g‘ri brauzerga beradi.
Backend route yozmasdan.

3/  Server joylashgan papkani ol (__dirname) va uning ichidagi public papkani top (path.join)
---------------------------------------------------------------------------------------------------------
app.use(express.urlencoded({ extended: true })); =>  Bu middleware HTML formdan kelgan POST ma’lumotlarni req.body ichiga joylab beradi. 
ya'ni backend tushunadigan tilga o'girib beradi
---------------------------------------------------------------------------------------------------------
app.use(express.json()); => frontenddan JSON ko‘rinishida kelgan ma’lumotlarni o‘qib, req.body ga solib beradi.
---------------------------------------------------------------------------------------------------------
